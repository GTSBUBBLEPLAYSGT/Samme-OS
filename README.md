Samme-OS

Welcome to **Samme-OS**, a custom Linux distribution built on an **Ubuntu** base, explicitly designed and optimized for **KingSammelot** fans! 

Developed by **GTSBUBBLE**, Samme-OS brings a fully customized desktop experience tailored to the community's aesthetic, built on top of the highly customizable **KDE Plasma** desktop environment.

---

Features
**Custom KingSammelot Theme:** Pre-configured desktop layouts, wallpapers, and color accents celebrating the community.
**Ubuntu Reliability:** Rock-solid stability out of the box with extensive hardware and gaming compatibility.
**KDE Plasma Interface:** A beautiful, responsive, and familiar desktop environment that makes switching to Linux easy.
**Ready for Gaming:** Smooth performance optimization for community-favorite apps and games.

---

Getting Started

Prerequisites
To test or install Samme-OS, you will need:
A blank USB drive (minimum 8GB)
A tool to flash the image (like [Rufus](https://rufus.ie) or [BalenaEtcher](https://balena.io))
A computer or Virtual Machine (like VirtualBox or VMware) to run the operating system

Installation Steps
1. **Download the ISO:** Grab the latest `.iso` file from our **Releases** tab on the right side of this repository.
2. **Flash the Image:** Open your flashing tool (e.g., BalenaEtcher), select the downloaded `Samme-OS.iso`, select your USB drive, and click **Flash**.
3. **Boot into Samme-OS:** Plug the flashed USB into your machine, restart, and press your system's boot menu key (usually F12, F11, or Del) to select the USB drive.
4. **Install:** Follow the on-screen Ubuntu/KDE installer to configure your language, disk settings, and account.
